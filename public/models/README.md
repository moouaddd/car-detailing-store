# Models

`wind-shield-pro.glb` is the hero bottle. It is generated by
`blender/build_wind_shield_pro.py` (Blender source file lives next to it, outside
`public/` so it is not served). To rebuild:

    blender --background --factory-startup --python blender/build_wind_shield_pro.py -- <out_dir>

then copy `<out_dir>/wind-shield-pro.glb` here.
